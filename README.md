# SupportPilot Frontend

A React + Vite frontend for the SupportPilot workspace management app.

## Getting started

1. Install dependencies:
   npm install
2. Start the app:
   npm run dev
3. Open the app in a browser:
   http://localhost:4173

## Scripts

- npm run dev — starts the Vite dev server on port 4173
- npm run build — creates a production build
- npm run lint — runs ESLint
- npm run preview — serves the production build locally on port 4173

## Notes

This project expects the backend API to be available at the value configured in VITE_API_URL, or defaults to http://localhost:5000/api.
